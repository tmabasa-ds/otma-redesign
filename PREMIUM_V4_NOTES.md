# OTMA Premium V4

This pass is a visual re-art-direction, not a cosmetic iteration.

## Design direction
- Full-bleed photographic homepage hero using the real OTMA crew and fleet.
- Source Serif 4 for editorial display typography and Manrope for interface/body copy.
- Real OTMA photography carries the page rather than decorative cards or generic icon grids.
- Reduced small uppercase labels, numbered modules, boxed cards, floating captions and SaaS-like dashboard patterns.
- Restrained OTMA blue used as an accent rather than flooding every surface.
- Larger editorial image sections and quieter content rhythm.
- Full-bleed image heroes on secondary service pages.
- Quote wizard functionality retained and visually recast as a premium move-brief experience.
- Mobile remains first-class, including Call / WhatsApp / Get Quote quick actions.

## Functional scope preserved
The existing detailed quote / move-brief workflow remains in `components/QuoteWizard.tsx`, including address selection, move type, room-by-room inventory, packing/material needs, access constraints, move date/time, contact details, confirmation channel, consent and optional photo uploads.
